Bienvenue sur Hashkao.com ! Ce générateur de mots de passe vous propose deux modes : aléatoire et créatif.

Mode aléatoire

En mode aléatoire, un mot de passe est généré automatiquement avec 12 caractères par défaut. Vous pouvez :

  • Générer un nouveau mot avec le bouton ⟳.
  • Modifier le nombre de caractères avec le curseur (jusqu'à 30).
  • Générer des anagrammes du mot de passe.
  • Activer/désactiver les options : éviter les doublons, exclure les caractères similaires.
  • Ajuster les proportions de minuscules, majuscules, chiffres, et caractères spéciaux avec les curseurs.
  • Personnaliser les caractères spéciaux utilisés (32 proposés).
  • Copier le mot de passe généré.
  • Mémoriser jusqu'à 9 mots de passe et exporter en fichier texte (.txt).

Mode créatif

Le mode créatif permet de partir d'une base manuelle ou d'importer un mot du mode aléatoire pour l'ajuster. Vous pouvez :

  • Importer un mot du mode aléatoire.
  • Modifier manuellement votre mot de passe (ajouter/supprimer des lettres).
  • Inverser le mot affiché.
  • Générer des anagrammes du mot affiché.
  • Mettre en majuscule une lettre après l'autre (ou en minuscule avec double-clic).
  • Tout passer en majuscule ou en minuscule en un clic.
  • Sécuriser automatiquement votre mot en renforçant sa structure.
  • Insérer des mots aléatoires, des mots existants ou des phrases générées selon plusieurs modes (gauche, droite, milieu...)

Autres fonctionnalités

  • Changer le thème sombre / clair pour l'interface.
  • Ajuster la police et la taille du mot de passe avec la fenêtre flottante "Ajuster le texte".
  • Exporter vos créations pour les conserver.
  • Réinitialiser pour repartir sur une session vierge.
